# arXiv Submission Instructions

1. Go to https://arxiv.org/submit
2. Create account or login
3. Select "Computer Science" → "Artificial Intelligence" (cs.AI)
4. Upload PAPER_FINAL.md (convert to PDF first)

To convert to PDF on Termux:
  pkg install pandoc texlive-installer
  pandoc docs/PAPER_FINAL.md -o docs/PAPER_FINAL.pdf

5. Title: "Sphota: O(n) Attention via Vedic Mathematics"
6. Authors: Joydeep Das
7. Abstract: Copy from paper
8. Submit

After submission, you get a permanent arXiv ID (e.g., arXiv:2605.xxxxx)
that can be cited forever.
